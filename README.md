# UCAS选课模拟器

支持预设选择与自定义 JSON 数据导入的选课模拟工具。当前预设来自国科大 SEP 选课系统：2026 年秋季开课数据（包含完整开班信息），以及 2027 年春季计划开课数据（无完整开班信息）。四个地区预设分别为京内学院、京外学院、研究所、培养基地，春季计划随京内学院预设提供。工具逻辑与课程数据分离：页面轻量，数据按需加载（在线版 / 本地起服务打开）。

## 功能

- **课程浏览**：默认京内预设共 3559 门课程（秋季 2079 + 春季 1480），支持按开课院系、一级/二级学科、课程类别、校区、学分、学期筛选；学期、院系、学科、课程类别、校区、学分、考试方式、星期均支持多选和选项搜索，同项取并集、不同项取交集；关键词搜索覆盖课程名、编码、学院、学科、教师、教室、授课/考试方式等
- **详细排课信息**：秋季学期接入官网正式排课数据——上课时间、教室、开课周、任课教师（首席 / 主讲 / 助教 / 召集人）、培养层次、授课方式、考试方式、限选 / 已选人数与剩余名额；点击课程名可查看完整详情
- **已选课程**：星标选课，保存在浏览器本地，可一键导出 CSV（含全部字段）；抽屉中可查看课程的完整信息（上课安排、教师、授课/考试方式、选课人数等）
- **模拟课程表**：网格视图（周一~周日 × 第 1–13 节），支持「整学期」总览与「每周」两种视图（含校历日期：秋季 2026-08-31 起 20 周、春季 2027-02-22 起 16 周），每周模式可用 ‹ › 箭头快速换周模拟当周上课情况
- **自动冲突检测**：同时考虑星期、节次、周次交集，冲突课程在课表中红色标记，并列出具体冲突周次

## 数据来源

| 文件 | 用途 |
|---|---|

| `datas/2026年秋季学期课表-研究所.xlsx` | 研究所秋季排课数据 |
| `datas/2026年秋季学期课表-基地.xlsx` | 培养基地秋季排课数据 |
| `2026-2027学年秋季和春季开课计划表0903.xlsx` | 春季学期开课计划数据（官网 0903 更新版） |

秋季学期以官网正式排课表为准；春季学期沿用开课计划，暂无具体排课信息。

## 课程大纲采集

秋季学期课程大纲已从国科大教务公开目录采集，保存在 `syllabi/` 目录：

- `course_syllabi.json`：2078 门课程的结构化大纲（目的要求、大纲内容、教材、参考书等），字段缺失留空
- `course_syllabi.csv`：课程编码与大纲链接索引
- `unmatched.csv`：未匹配/下载失败的课程
- `scrape_syllabi.py`：采集脚本（缓存 + 断点续跑 + 低频请求）

重新采集：`python3 syllabi/scrape_syllabi.py`。原始 HTML 缓存于 `syllabi/raw/`（已在 .gitignore 中，可再生成）。

## 使用

- **在线版**（推荐）：直接访问 GitHub Pages，或本地起服务后打开：`python3 -m http.server`，浏览器访问 `http://localhost:8000/`。
- **本地双击 index.html（file://）**：因浏览器安全限制读不到同目录 `presets/*.json`，页面会提示——可点「导入课程数据」手动选择，或改用上面的本地服务器方式。

## 工具与数据分离

页面本身只含工具逻辑（~70KB），课程数据外置在 `presets/`，启动时按需加载：

- `presets/manifest.json`：预设清单
- `presets/2026秋-京内.json / -京外.json / -研究所.json / -基地.json`：国科大四个地区预设（京内 3559，含秋季 2079 与春季计划 1480 / 京外 449 / 研究所 392 / 基地 59 门）
- 首页「选择预设数据集」面板可勾选组合预设；也可用「导入课程数据」接入其他学期/其他来源数据

数据重新生成：`cd build && ./build.sh`（读取 `datas/*.xlsx` 官网导出与开课计划，产出 presets 与页面）。

## 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库（本项目对应 `AaronChou313/UCAS-lessons`）
2. 进入仓库 **Settings → Pages**，在 "Build and deployment" 中选择 **Source: Deploy from a branch**，分支选 `master`（或 `main`），目录选 `/ (root)`
3. 保存后站点即可通过 `https://<用户名>.github.io/<仓库名>/` 访问（本项目为 `https://AaronChou313.github.io/UCAS-lessons/`）

`index.html` 即站点入口，无需构建步骤。仓库根目录已包含空的 `.nojekyll` 文件，用于告诉 GitHub Pages 跳过 Jekyll、原样托管静态文件（否则 Jekyll 会把页面套上默认主题）。

## 更新数据（重新生成页面）

将更新后的官网导出放入 `datas/`（课表 xlsx）与项目根目录（开课计划 xlsx）后运行：

```bash
cd build && ./build.sh
```

生成流程：

1. `build_data.py`：解析 datas 京内课表 + 官网春季开课计划，合并为 `courses_merged.json`
2. `build_presets.py`：由 datas 四份课表与开课计划生成 `presets/*.json` + `manifest.json`
3. 拷贝 `template.html` 为 `index.html`（页面不内嵌课程数据）

## 说明

- 校区由课程编码尾字母推断：H = 雁栖湖、Y = 玉泉路、Z = 中关村
- 一级 / 二级学科由课程编码自动归类，自设、交叉或无法唯一识别的学科归入「其他 / 自设学科」
- 节次时段（如第 1 节 08:00 起）为常见授课时间，仅供参考
- 本页面仅用于选课模拟，最终开课与排课情况以学校实际发布为准


## 导入其他学校的数据

首页点击「导入课程数据」选择 JSON 文件（可多选），会替换当前数据；点击「选择预设数据集」可切回国科大数据。文件在浏览器中读取，不会上传，刷新后恢复预设。

文件内容为课程对象数组，可参考 `presets/2026秋-基地.json` 的结构。每门课程至少提供 `code`（课程编码）、`name`（课程名）、`semester`（完整学期名称，如 `2028年夏季学期`，筛选项从数据自动生成）、`college`、`first`、`second`、`category`、`campus`（均为字符串）、`credits` 和 `hours`（数字）；无对应分类时填空字符串。`slots` 为排课数组，无排课时填 `[]`。每项包含 `day`（星期 1–7）、`start` / `end`（起止节次 1–13）、`p`（如 `1-2`）、`w`（如 `1-16周`）。可补充 `main`（教师）、`room`（教室）等字段。

目前课表仍使用国科大的节次时段；2026 年秋季和 2027 年春季可显示预设校历日期，其他学期按教学周显示，不套用国科大日期。导入其他学校的数据时需对应这些节次；自定义校历与节次尚未提供配置入口。
